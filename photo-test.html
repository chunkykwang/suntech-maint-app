ทดสอบรูป offline

…

โหลดรูปเก็บในเครื่องตอนมีเน็ต แล้วเปิดดูตอนไม่มีเน็ต

A. รูปตัวอย่าง (ไม่ต้องใช้ API)

รูปทดสอบ 4 รูป รูปละ ~120 KB ขนาดใกล้เคียงรูป Hint จริง ทดสอบว่า iPhone เก็บรูปไว้ในเครื่องและเปิดตอน offline ได้

B. รูป part จริง (ผ่าน API + PIN)

ดึงรูปจากโฟลเดอร์ Partlist › Photos ผ่าน Apps Script ต้องตั้งลิงก์ API แล้วและมี PIN

ขั้นทดสอบ

1) เปิดจากไอคอนบนหน้าจอโฮม ตอนมีเน็ต → กด "โหลดเก็บในเครื่อง" ให้รูปขึ้นครบ
2) เปิดโหมดเครื่องบิน → ปัดปิดแอป → เปิดใหม่จากไอคอน → เข้าหน้านี้
3) ผ่าน = รูปยังขึ้นครบ และป้าย "ที่เก็บในเครื่อง" มีตัวเลข
